# 裁判评分系统 🏅

基于 Streamlit 的裁判评分 Web 应用，支持答辩组和实操组两类裁判在线评分。

## 功能

- **裁判登录**：姓名 + 编号 + 组别选择，URL 自动记住登录状态
- **分组评分**：
  - 答辩组：大模型思路讲解/语音交互方案(30)、视觉流程(30)、机器人控制(30)、创新性/答辩流畅(10)
  - 实操组：语音交互(12)、大模型任务卡解析(34)、装配流程(24)、装配精度(30)
- **表格式按钮评分**：每个评分项独占一行，并列出该项全部可选分值
- **实操扣分与否决**：9项手动填写扣分，2项否决勾选后总分归零
- **装配精度**：按钮显示偏移量及对应得分，支持小数分值
- **数据记录**：所有评分自动保存，支持实时查看
- **Excel 导出**：一键导出评分记录为 Excel 文件
- **移动端适配**：手机浏览器即可使用

## 快速开始

### 本地运行

```bash
# 安装依赖
pip install -r requirements.txt

# 启动应用
streamlit run app.py
```

### 部署到 Streamlit Cloud

1. 将代码推送到 GitHub 仓库
2. 访问 https://share.streamlit.io/
3. 点击 "New app" → 选择仓库 → Deploy
